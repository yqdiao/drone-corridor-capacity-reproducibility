\section*{Data and code availability}
No proprietary or person-level data were used. The complete public replication package is available in the \href{https://github.com/yqdiao/drone-corridor-capacity-reproducibility}{GitHub repository for this study}. The repository contains the figure-generation program, complete machine-readable values behind every plotted curve, all 30,000 design-space draws, exact symbolic checks, strict-domain tests, and publication-ready figures for the resource-productivity model. Its pinned software environment and the single command \texttt{make reproduce} regenerate the five figures, numerical summaries, and verification results. Appendix~\ref{app:current-audit} documents the scenario design and verification scope.
